# 失败分类（重生时只改对应约束）

整表/整图不合格时，先归类，再改 **一类** 约束后重生。禁止「整段 Prompt 推倒重写」把脸和服装一起漂掉。

| 类 | 现象 | 只改 | 保留不动 |
|---|---|---|---|
| **scale** 身尺漂 | 邻格头忽大忽小；豆人；武器挤空间把人压小 | `[SCALE]`；参考图加上 `scale_ref`/run0；Prompt 重申弯膝不缩全身 | identity、parts id、帧序语义 |
| **likeness** 人不像 | 换脸、换装、标志物没了、画风漂 | `[IDENTITY]`；加强立绘参考；复述 signature/forbid | 动作帧序、格数 |
| **motion** 动作错/不连贯 | 姿势不对；邻帧换肢、瞬移、跳色 | `[POSE]`、帧列表、`key_cell`；必要时重做关键定格 A | 配色、头身描述 |
| **crop** 切格失败 | 跨格、贴边、刃/弓被切、gutter 不够 | `[CANVAS]` 宽 gutter；收肢/收武器进格；禁画格线进角色 | 角色身份 |
| **prop** 持物穿帮 | 弓/剑消失、换手、穿模 | `[PARTS]` 里 prop/deco 句；参考图含持物清晰立绘 | 腿部跑法（若跑已合格） |
| **matte** 幕布脏 | 场景底、灰框、键色残边 | 幕布句；透明要求；产品 chroma/plant | 姿势配方 |

## 流程

```
失败 → 归一类（可多类则按 scale → likeness → crop → motion → prop 顺序）
    → 只改该类块 + 同参考图策略
    → 整图/整表重生
    → 再验收
```

一帧坏了仍是 **整表重生**（禁单格挖补）；分类只决定 **改 Prompt 的哪一块**，不授权挖补。
