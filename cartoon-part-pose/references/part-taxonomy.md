# 部位分类（中粒度默认 / 细粒度可选）

**默认 = 语义拆分**：稳定 id + 外观备注，配合立绘参考生成整图。  
**不是**默认把头/四肢抠成可旋转 PNG。用户点名「真切件 / cutout」才升 `split_mode: cutout`（另管线，本 skill 不展开拼装 IK）。

## 中粒度（默认）

| id | 含什么 | 不含（除非用户升档） |
|---|---|---|
| `head` | 头型、发型、通常含五官 | 独立瞳孔层 |
| `face` | 可选；换表情时从 head 分出 | 每根睫毛 |
| `torso` | 胸腹、上衣、腰带主体 | 每颗纽扣单件 |
| `arm_upper_*` | 上臂 + 袖上段 | — |
| `arm_lower_*` | 前臂 + 袖下段 | — |
| `hand_*` | 手掌手指整体 | 每指关节 |
| `leg_upper_*` | 大腿 + 裤/裙上段 | — |
| `leg_lower_*` | 小腿 | — |
| `foot_*` | 鞋/脚整体 | — |
| `prop_*` | 一件手持物一件 id | 特效粒子可另 `fx_*` |
| `deco_*` | 披风、尾、飘带、帽饰等 | — |

`*` = `L` / `R`。

## 细粒度（仅用户要求时）

在中粒度上追加，例如：

- `eye_L` / `eye_R` → 可选再拆 `eyelid` / `iris` / `highlight`
- `brow_L` / `brow_R` / `mouth`
- `hair_front` / `hair_back`
- `skirt_panel` / `cloak_layer`

**升档前问用户**：要细到哪一层，避免过度拆件拖慢流程。

## 命名

- 小写 + 下划线；左右后缀 `_L` `_R`
- 道具：`prop_bow`、`prop_staff`；装饰：`deco_cape`
- 同一角色多动作 **禁止改名**；新增部位只追加
